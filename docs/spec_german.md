AI-Therapist: 

Vision/ Ziele: 

UI

1) Chatfenster
2) Ziele (definiert), beim ersten öffnen wird man nach Ziele gefragt 
3) Einblicke (inisghts) Grafiken im Detail (man sieht das man sich verbessert (statistisch gezeuigt von den fragen))
4) notifications (wie war dein Tag, muss man ausfüllen, mit Fragen, ist alles so besprochen, kurzes checkup, user getrieben, Ziele, getrieben, user-spezifisch, wird am Anfang erfragt durch AI)

Ziel: 

1) Wohlfühlraum mit Avatar, Gesprächsraum, alles kann man sagen, Therapie-sessions, es startet und Endet, es gibt klare Zeiten 
2) Ziele sollen über die Zeit geschafft werden, Karriere, Beziehung, 

Backend 

1) Brain -> AI hat Daten über User, die über die Zeit mehr werden, Entitätsextraktion, Relationen zwischen Entitäten, alles wird in Datenbank gespechert, sehr user-spezifisch 
2) Klare Schnittstelle zwischen APP -> Model-provider (derzeit OPenAI) kann ausgewechselt werden zu andere Provider (base-calsse) -> Abgeleitet)
